# AlgoFlow_SDG8_FinalProject-EMPLOYEE-MANAGEMENT-
Final Project for IT Elective(Dela Cruz, Diaz, Villalon)

This VB.NET Windows Forms application is developed to support United Nations SDG 8: Decent Work and Economic Growth by digitizing and streamlining workforce management. The system enhances operational efficiency by providing a reliable and transparent platform for monitoring employee attendance and work hours, which is crucial for ensuring fair labor practices and productive workplace environments. The system uses Microsoft SQL Server with ADO.NET for database connectivity and includes features such as:

-Log-in System

-Employee Attendance and Work Hours Record Management

-CRUD operations

By replacing manual, error-prone record-keeping with this automated database-driven solution, the project helps businesses adopt more efficient and sustainable labor management practices, ultimately fostering an environment where decent work and economic growth can thrive.
